# Project Constitution

## Universal Rules (Apply to Every Project)
- Never say "Done" or "Fixed" before seeing a successful build/test output.
- Never delete, truncate, or replace functions you are not explicitly changing.
- Prefer the smallest possible diff — touch only what needs to change.
- Never invent file paths. Always use FindFiles or ListDirectory to discover the real structure first.
- If a request is ambiguous, ask ONE clarifying question before writing any code.
